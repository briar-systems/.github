# briar-systems/.github

Org-wide community health files and the org profile (`profile/`). GitHub applies the issue templates, the pull request template, CONTRIBUTING, SECURITY, SUPPORT and the code of conduct to every repository in the org that has none of its own.

CI is not shared. Each repository owns its `.github/workflows/ci.yml` and `cd.yml`. A new mach project starts from [mach-template](https://github.com/briar-systems/mach-template).
